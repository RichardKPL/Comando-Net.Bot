# Referência de comandos

Nomes e descrições conferidos nos decoradores dos módulos. A visibilidade e a execução dependem das permissões, dos canais e dos cargos configurados no servidor.

| Comando | Descrição | Módulo |
| --- | --- | --- |
| `/ajuda` | Exibe um menu interativo com os guias de uso do bot. | `Info_Ajuda.py` |
| `/ausencia` | Registrar ausência de um membro. | `Gerenciador_Ausencias.py` |
| `/funcionalcargos` | Definir cargos disponíveis | `Gerenciador_Funcional.py` |
| `/info` | Apresenta um resumo sobre mim e meu desenvolvedor. | `Info_Info.py` |
| `/rso` | Abre o painel para iniciar um novo Relatório de Serviço Operacional (RSO). | `Gerenciador_RSO.py` |
| `/setadminfuncional` | Define os cargos que podem aprovar/reprovar funcionais. | `Gerenciador_Funcional.py` |
| `/setadmintransferencia` | Definir cargos de aprovação de transferência | `Gerenciador_Transferencias.py` |
| `/setausencia` | Cria um painel público de ausências. | `Gerenciador_Ausencias.py` |
| `/setausenciacanal` | Define o canal onde as ausências serão enviadas. | `Gerenciador_Ausencias.py` |
| `/setboletim` | Cria o painel interativo para emissão de boletins. | `Gerenciador_Boletim.py` |
| `/setboletimcanal` | Define o canal de envio dos boletins usando um menu interativo. | `Gerenciador_Boletim.py` |
| `/setbopm` | Envia o painel de BO PM para o canal selecionado. | `Gerenciador_BOPM.py` |
| `/setcargos` | Adicionar ou remover múltiplos cargos de um usuário. | `Gerenciador_Cargos.py` |
| `/setfuncional` | Envia embed público para solicitar funcional | `Gerenciador_Funcional.py` |
| `/setfuncionalap` | Definir canal de aprovação | `Gerenciador_Funcional.py` |
| `/settransferencia` | Envia embed público para solicitar transferência | `Gerenciador_Transferencias.py` |
| `/settransferenciaap` | Definir canal de aprovação de transferências | `Gerenciador_Transferencias.py` |
| `/status` | Mostra informações e o status atual do bot. | `Info_Status.py` |
| `/transferenciacargos` | Definir cargos para transferência | `Gerenciador_Transferencias.py` |

Use `/ajuda` para os guias interativos. Ao adicionar ou renomear comandos, atualize esta referência.
